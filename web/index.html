🔒 Coffman Deadlock Conditions

All four conditions must hold simultaneously for a system deadlock to manifest:

  • Mutual Exclusion: Exclusive non-shareable resource ownership.
  • Hold & Wait: Threads holding resources while requesting additional ones.
  • No Preemption: Resources can only be released voluntarily by the owner.
  • Circular Wait: Closed cycle of threads waiting for next thread's resource.
// Prevention: Dijkstra hierarchy or total capacity - 1 sem_t entry_permit; // Breaks circular wait!

🌐 BSD Sockets Architecture

Standard life-cycle state transitions for concurrent TCP servers and clients:

Server: socket() -> bind() -> listen() -> accept() -> recv/send() -> close() Client: socket() -> connect() -> send/recv() -> close()

In multi-threaded servers, accept() delegates the active client fd to a worker thread from a pool.
